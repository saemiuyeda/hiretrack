# MVP

## Objetivo do MVP

Criar uma primeira versão funcional para centralizar e acompanhar candidaturas.

## Funcionalidades Incluídas

### Gerenciamento de candidaturas

O usuário poderá:

- Cadastrar uma candidatura;
- Visualizar candidaturas cadastradas;
- Editar informações de uma candidatura;
- Excluir uma candidatura.

### Informações registradas

Cada candidatura poderá conter:

- Vaga;
- Empresa;
- Status;
- Plataforma/Canal;
- Data de candidatura;
