# Análise do Problema

Durante processos de candidatura a oportunidades profissionais, o candidato precisa gerenciar informações provenientes de diferentes vagas, empresas e etapas de seleção. A ausência de uma centralização dessas informações dificulta o acompanhamento dos processos seletivos, dos respectivos status e dos feedbacks recebidos.

Além disso, os dados gerados durante a busca por oportunidades, como requisitos recorrentes das vagas, tecnologias solicitadas, etapas de eliminação e resultados obtidos, possuem potencial para auxiliar na tomada de decisões estratégicas, mas frequentemente não são registrados ou analisados de forma estruturada.

# Problema Identificado

As informações relacionadas aos processos seletivos encontram-se dispersas em diferentes ferramentas e registros, dificultando a organização das candidaturas e a identificação de padrões durante a busca por oportunidades.

Além disso, para obter análises relevantes, é necessário coletar uma quantidade suficiente de dados sobre cada candidatura. Entretanto, processos de registro excessivamente complexos podem aumentar o esforço necessário para utilização do sistema, reduzindo a frequência de atualização das informações.

# Consequência

A falta de uma visão consolidada dos processos seletivos impede que o candidato utilize seus próprios dados para compreender sua evolução, identificar oportunidades de melhoria e tomar decisões mais estratégicas durante sua busca profissional.

# Restrições Identificadas

O sistema deve equilibrar a quantidade de informações coletadas com a simplicidade de utilização, garantindo que o registro das candidaturas seja eficiente o suficiente para incentivar a utilização contínua, mas completo o suficiente para possibilitar análises futuras.

# Oportunidades Futuras

A estruturação dos dados das candidaturas permitirá futuramente gerar análises relacionadas a padrões de oportunidades, requisitos recorrentes e evolução profissional.
